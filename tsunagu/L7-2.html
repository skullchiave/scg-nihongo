ない形けいの つくりかた

まず グループを 見分みわけて、ませんから ない形けいに かえる。

1グループ

「ません」の まえ（い段だん）を あ段だんに かえて ＋ない
いきません → いかない
のみません → のまない
はなしません → はなさない
よびません → よばない

2グループ

「ません」を とって ＋ない
たべません → たべない
みません → みない
あけません → あけない
あびません → あびない

3グループ

2つだけ（おぼえる）
（学校へ）きません → こない
しません → しない
さんぽしません → さんぽしない
べんきょうしません → べんきょうしない
ちゅうい： 「い」が あ段だんに かわると わ に なる：かいません → かわない ／ あいません → あわない（×かあない）
ありません は ない（×あらない）。
おなじ おと・べつの ことば： （あさ）おきません→おきない（2グループ）と （ほんを）おきません→おかない（1グループ）。（学校へ）きません→こない（3グループ）と （シャツを）きません→きない（2グループ）。
