「なかった」（過去否定かこひていの 普通形ふつうけい）の つくりかた

ない形けい（7-2）の 「ない」を「なかった」に かえるだけ。「ませんでした」の カジュアルな いいかた。

1グループ

「ませんでした」の まえ（い段だん）を あ段だんに かえて ＋なかった
いきませんでした → いかなかった
のみませんでした → のまなかった
かきませんでした → かかなかった
はなしませんでした → はなさなかった

2グループ

「ませんでした」を とって ＋なかった
たべませんでした → たべなかった
みませんでした → みなかった
あけませんでした → あけなかった
（あさ）おきませんでした → おきなかった

3グループ

2つだけ（おぼえる）
（学校へ）きませんでした → こなかった
しませんでした → しなかった
べんきょうしませんでした →
べんきょうしなかった
ちゅうい： 「い」は あ段だんで わ に なる：かいませんでした → かわなかった（×かあなかった）
ありませんでした は なかった（×あらなかった）。
ない形けいを しっていたら かんたん：いかない → いかなかった ／ こない → こなかった（ない → なかった）。
おなじ おと・べつの ことば： （あさ）おきませんでした→おきなかった（2グループ）と （ほんを）おきませんでした→おかなかった（1グループ）。（学校へ）きませんでした→こなかった（3グループ）と （シャツを）きませんでした→きなかった（2グループ）。
